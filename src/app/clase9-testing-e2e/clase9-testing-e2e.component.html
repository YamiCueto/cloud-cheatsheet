Genera tests [NIVEL] para mi [COMPONENTE/SERVICE/CONTROLLER]:

**Código a Probar:**
```[LENGUAJE]
[CÓDIGO_COMPLETO_AQUÍ]
```

**Contexto:**
- Framework: [Angular/Spring Boot]
- Testing tool: [Jasmine/JUnit/Cypress]
- Tipo: [Unitario/Integración/E2E]

**Requerimientos:**
- Casos a cubrir: [éxito, error 404, error 500, validaciones]
- Mocks necesarios: [HttpClient/Repository/Service]
- Assertions: [status codes, JSON response, excepciones]
- Setup: [@BeforeEach para datos iniciales]

**Entregable:**
Archivo [nombre].spec.ts o [nombre]Test.java con:
- describe/it (Jasmine) o @Test (JUnit)
- Mocks configurados correctamente
- Assertions claras con expect() o assertEquals()
- Casos: happy path + edge cases + errores

🎯 Variables a personalizar:

  • [NIVEL]: unitarios, de integración, E2E
  • [COMPONENTE/SERVICE/CONTROLLER]: ClienteService, ProductoController, etc.
  • [LENGUAJE]: TypeScript, Java, JavaScript
  • [CÓDIGO_COMPLETO_AQUÍ]: pega método/clase completa a probar
