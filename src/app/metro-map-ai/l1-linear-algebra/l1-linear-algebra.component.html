🧮 ¿Por qué Álgebra Lineal en IA?

El álgebra lineal no es solo matemática abstracta — es la infraestructura computacional de toda la IA moderna. Desde un perceptrón hasta GPT-4, todo se reduce a multiplicaciones de matrices y operaciones vectoriales.

🔑 Eigenvalores & SVD

Las descomposiciones matriciales revelan la geometría oculta de los datos. Eigendecomposición para matrices cuadradas simétricas (covarianza). SVD para cualquier matriz — la base de PCA, recomendación y compresión.

🐍 Python · NumPy
{{ decompExamples[activeDecompTab].code }}
▶ Output 
{{ decompExamples[activeDecompTab].output }}
Eigendecomposición

A = Q · Λ · Q⁻¹ (solo matrices cuadradas)

→ PCA, análisis de estabilidad, Google PageRank

SVD

A = U · Σ · Vᵀ (cualquier matriz m×n)

→ Compresión, recomendación, pseudoinversa, LSA

Cholesky

A = L · Lᵀ (matrices semidefinidas positivas)

→ Muestreo Gaussiano, filtro de Kalman, GPs
