🤔 ¿Por qué Álgebra Lineal en IA?

Una red neuronal es álgebra lineal: matrices de pesos, vectores de activación, transformaciones del espacio. Sin entenderla, no puedes debuggear shapes, optimizar memoria, ni leer papers.

🧠

Pesos como matrices

Cada capa densa es W·x + b. Una red de 100 capas = 100 multiplicaciones matriciales encadenadas.

📊

Embeddings = vectores

word2vec, BERT, LLaMA — las palabras son vectores en espacio 768D o 4096D. La similitud coseno es álgebra lineal.

🗜️

Reducción dimensional

PCA, SVD, t-SNE — comprimen datos de miles de dimensiones a 2-3 para visualización o eficiencia.

⚡

GPUs = matrix engines

Las GPUs están optimizadas para multiplicaciones matriciales masivas en paralelo. Álgebra lineal = hardware moderno.

🔄

Backpropagation

El gradiente se propaga mediante la regla de la cadena — que es multiplicación de Jacobians (matrices de derivadas parciales).

🎯

Attention = matrices

Attention(Q,K,V) = softmax(QK^T/√d_k)V. Transformers son pura álgebra lineal sobre matrices de queries, keys y values.

🔲 Matrices: transformaciones del espacio

Una matriz es una función lineal: transforma vectores de entrada en vectores de salida. Cada capa de una red neuronal aplica una transformación matricial seguida de una activación no-lineal.

Transpose A.T

Intercambia filas y columnas. Esencial para alinear shapes en multiplicaciones.

Inversa A⁻¹

Deshace la transformación. Costosa: O(n³). Evitar en sistemas grandes.

Determinante

Mide el "volumen" de la transformación. det=0 → matriz singular (no invertible).

Rango (rank)

Dimensiones independientes. Rank < n → información perdida (degenerada).

🧮 Multiplicación Matricial — El latido del DL

La multiplicación A @ B es la operación más ejecutada en deep learning. GPUs existen específicamente para acelerarla. Entender las reglas de shapes es crítico.

import numpy as np

# REGLA: (m×k) @ (k×n) = (m×n)
# La dimensión interna debe coincidir

# Ejemplo: batch de imágenes flatten a través de capa densa
batch_size = 32
input_features = 784   # 28×28 píxeles
hidden_units = 256
output_units = 10      # 10 clases MNIST

X  = np.random.randn(batch_size, input_features)  # (32, 784)
W1 = np.random.randn(input_features, hidden_units) * 0.01  # (784, 256)
b1 = np.zeros(hidden_units)  # (256,)

# Capa 1: (32,784) @ (784,256) = (32,256)
Z1 = X @ W1 + b1
A1 = np.maximum(0, Z1)   # ReLU

W2 = np.random.randn(hidden_units, output_units) * 0.01  # (256, 10)
b2 = np.zeros(output_units)

# Capa 2: (32,256) @ (256,10) = (32,10)
Z2 = A1 @ W2 + b2

# Softmax → probabilidades
exp_z = np.exp(Z2 - Z2.max(axis=1, keepdims=True))  # num stable
probs = exp_z / exp_z.sum(axis=1, keepdims=True)

print(f"Input:   {X.shape}")
print(f"Hidden:  {A1.shape}")
print(f"Output:  {probs.shape}")        # (32, 10)
print(f"Suma prob: {probs.sum(axis=1)[:3].round(4)}")  # todas = 1.0
▶ Output
Input:   (32, 784)
Hidden:  (32, 256)
Output:  (32, 10)
Suma prob: [1. 1. 1.]
⚠️ Error más común: ValueError: matmul shapes mismatch. Siempre verifica .shape antes de @. El error dice qué dimensiones no coinciden.

🔑 Eigenvalores y Eigenvectores

Un eigenvector v de matriz A es un vector que solo se escala (no rota) al aplicar la transformación: Av = λv. Los eigenvalores λ dicen cuánto se escala.

import numpy as np

# Matriz de covarianza de un dataset 2D
np.random.seed(42)
X = np.column_stack([np.random.randn(100),
                     2 * np.random.randn(100)])  # 2a dimensión más variable

cov_matrix = np.cov(X.T)
print("Matriz de covarianza:\n", cov_matrix.round(2))

# Eigendescomposición
eigenvalues, eigenvectors = np.linalg.eig(cov_matrix)
print("\nEigenvalores:", eigenvalues.round(2))
print("Eigenvectores (columnas):\n", eigenvectors.round(2))

# Interpretación: el eigenvector con mayor eigenvalor
# apunta en la dirección de mayor varianza = 1er componente principal
idx = np.argsort(eigenvalues)[::-1]  # ordena descendente
print("\nPrimer componente principal:", eigenvectors[:, idx[0]].round(2))
print("Varianza explicada: {:.1f}%".format(
    eigenvalues[idx[0]] / eigenvalues.sum() * 100))
▶ Output
Matriz de covarianza:
 [[1.05 0.09]
  [0.09 3.97]]

Eigenvalores: [1.05 3.97]
Primer componente principal: [0.02 1.  ]
Varianza explicada: 79.1%
💡 Aplicaciones en ML: PCA usa eigendescomposición de la covarianza. Spectral Clustering usa eigenvalores del Laplaciano de grafo. Google PageRank es el eigenvector dominante de la matriz de links.

🗜️ SVD y PCA

SVD (Singular Value Decomposition) descompone cualquier matriz A = UΣV^T. Es la madre de PCA, compresión de imágenes, sistemas de recomendación y reducción dimensional.

import numpy as np

# ── SVD para compresión de imagen ────────────────
imagen = np.random.randn(64, 64)  # simula imagen 64×64 pixels

U, sigma, Vt = np.linalg.svd(imagen)
print(f"U: {U.shape}, sigma: {sigma.shape}, Vt: {Vt.shape}")

# Reconstruir con solo k valores singulares (compresión)
def reconstruir_svd(U, sigma, Vt, k):
    return U[:, :k] @ np.diag(sigma[:k]) @ Vt[:k, :]

k = 10  # usar solo los 10 mayores valores singulares
imagen_k10 = reconstruir_svd(U, sigma, Vt, k)
varianza_explicada = (sigma[:k]**2).sum() / (sigma**2).sum() * 100
print(f"k={k}: {varianza_explicada:.1f}% de varianza explicada")

# ── PCA con SVD (sklearn lo hace así internamente) ─
np.random.seed(42)
X = np.random.randn(100, 50)  # 100 ejemplos, 50 features

# PCA manual
X_centrado = X - X.mean(axis=0)
U, S, Vt = np.linalg.svd(X_centrado, full_matrices=False)

# Proyectar a 2D (top-2 componentes)
X_2d = X_centrado @ Vt[:2].T
print(f"\nOriginal: {X.shape} → PCA 2D: {X_2d.shape}")
▶ Output
U: (64, 64), sigma: (64,), Vt: (64, 64)
k=10: 18.4% de varianza explicada
Original: (100, 50) → PCA 2D: (100, 2)

Imágenes, audio, texto — SVD encuentra la representación más compacta.

🐍 numpy.linalg: Toolkit completo

NumPy incluye un módulo completo de álgebra lineal basado en LAPACK y BLAS — las mismas librerías que usa MATLAB y R.

import numpy as np

# ── Función de referencia rápida ──────────────────
A = np.array([[4., 3.],
              [6., 3.]])

print("det(A):", np.linalg.det(A).round(2))          # -6.0
print("inv(A):\n", np.linalg.inv(A).round(2))        # inversa
print("rank(A):", np.linalg.matrix_rank(A))           # 2
print("trace(A):", np.trace(A))                       # 7.0 (suma diagonal)
print("norm(A):", np.linalg.norm(A).round(2))         # norma Frobenius

# Resolución de sistemas lineales Ax = b
b = np.array([1., 2.])
x = np.linalg.solve(A, b)  # más eficiente que inv(A) @ b
print("\nSolución Ax=b:", x.round(4))
print("Verificación:", (A @ x).round(4))  # debe ser [1, 2]

# Normas de vectores
v = np.array([3., 4., 0.])
print("\nNorma L1 (Manhattan):", np.linalg.norm(v, ord=1))  # 7
print("Norma L2 (Euclidiana):", np.linalg.norm(v, ord=2))  # 5
print("Norma Inf (Chebyshev):", np.linalg.norm(v, ord=np.inf))  # 4
▶ Output
det(A): -6.0
rank(A): 2
trace(A): 7.0
Solución Ax=b: [-0.5   1.  ]
Norma L1: 7.0   Norma L2: 5.0   Norma Inf: 4.0
💡 L1 vs L2 en ML: L1 regularización (Lasso) → sparsidad. L2 (Ridge) → pesos pequeños. Ambas son normas de vectores de parámetros, y controlan el overfitting.
