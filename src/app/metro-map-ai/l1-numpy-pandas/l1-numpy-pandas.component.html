📊 GroupBy y Merge

GroupBy agrupa datos por categorías — como SQL GROUP BY. Merge une DataFrames por claves comunes — como SQL JOIN. Esenciales para feature engineering.

import pandas as pd

# ── GroupBy ────────────────────────────────────────
ventas = pd.DataFrame({
    'region': ['Norte', 'Sur', 'Norte', 'Centro', 'Sur', 'Norte'],
    'producto': ['A', 'B', 'A', 'C', 'A', 'B'],
    'monto': [1200, 850, 1400, 600, 920, 1100]
})

# Agg con múltiples funciones
resumen = ventas.groupby('region')['monto'].agg(['sum', 'mean', 'count'])
print(resumen)

# GroupBy múltiples columnas
pivot = ventas.groupby(['region', 'producto'])['monto'].sum().unstack(fill_value=0)
print(pivot)

# ── Merge (JOIN) ───────────────────────────────────
clientes = pd.DataFrame({'id': [1, 2, 3], 'nombre': ['Ana', 'Luis', 'María']})
pedidos  = pd.DataFrame({'cliente_id': [1, 1, 2, 3], 'pedido': ['P1', 'P2', 'P3', 'P4']})

# Inner join
resultado = clientes.merge(pedidos, left_on='id', right_on='cliente_id')
print(resultado[['nombre', 'pedido']])

⚡ Tips de Rendimiento

Cuando el dataset tiene millones de filas, la forma en que escribes el código importa mucho. Aprende a perfilar y optimizar.

import numpy as np
import pandas as pd
import time

# ── 1. NUNCA uses loops en NumPy ──────────────────
arr = np.random.randn(1_000_000)

t0 = time.time()
resultado_loop = [x**2 for x in arr]
print(f"Loop Python: {time.time()-t0:.3f}s")

t0 = time.time()
resultado_np = arr**2                # vectorizado
print(f"NumPy vectorizado: {time.time()-t0:.3f}s")
# Loop: ~0.25s | NumPy: ~0.003s → 83x más rápido!

# ── 2. Usa tipos adecuados (menos memoria) ────────
df_grande = pd.DataFrame({'cat': ['A','B','C'] * 100_000})
print(f"object dtype: {df_grande.memory_usage(deep=True).sum()/1024:.1f}KB")
df_grande['cat'] = df_grande['cat'].astype('category')
print(f"category dtype: {df_grande.memory_usage(deep=True).sum()/1024:.1f}KB")

# ── 3. Prefiere operaciones sobre apply() ─────────
df = pd.DataFrame({'x': range(100_000)})
# Lento:  df['y'] = df['x'].apply(lambda x: x**2)
# Rápido: df['y'] = df['x'] ** 2

# ── 4. Usa chunksize para datos massivos ──────────
