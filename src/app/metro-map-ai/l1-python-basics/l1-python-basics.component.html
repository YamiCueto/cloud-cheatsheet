{{ dataStructureExamples[activeDataStructureTab].output }}
Lista []

Ordenada, mutable, acepta duplicados. Para datos secuenciales.

Diccionario {}

Clave-valor, acceso O(1). Para configuraciones y resultados.

Tupla ()

Inmutable. Para coordenadas, dimensiones, retornos múltiples.

Set {}

Sin duplicados. Para etiquetas únicas, operaciones de conjuntos.

⚙️ Módulos, Paquetes y Entorno Virtual

Un entorno virtual (venv) aísla las dependencias de cada proyecto. Es obligatorio en IA — distintos proyectos necesitan versiones diferentes de NumPy, PyTorch, etc.

{{ modulesExample.code }}

🔄 Flujo de trabajo estándar para proyectos IA

1
Crear entorno python -m venv venv_ia
→
2
Activar source venv_ia/bin/activate
→
3
Instalar deps pip install -r requirements.txt
→
4
Desarrollar jupyter notebook
→
5
Guardar deps pip freeze > requirements.txt
🚫 Nunca uses pip install sin entorno virtual activo — contaminarás las librerías del sistema y tendrás conflictos entre proyectos.
