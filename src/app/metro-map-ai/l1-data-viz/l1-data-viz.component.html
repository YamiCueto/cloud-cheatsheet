📊 ¿Por qué EDA antes de modelar?

El Análisis Exploratorio de Datos (EDA) es la fase donde un 80% del trabajo real de Data Science ocurre. Modelos entrenados sobre datos sucios producen predicciones incorrectas — garbage in, garbage out.

🐛

Detectar errores

Valores imposibles, fechas incoherentes, labels mal codificadas — invisibles sin EDA.

📐

Entender distribuciones

¿Normal? ¿Sesgada? ¿Multimodal? Esto dicta normalización y elección de modelo.

🔗

Revelar correlaciones

Features redundantes aumentan overfitting; features correladas con el target son oro.

⚖️

Detectar desbalance

Un modelo sobre el 99% de clase A y 1% de clase B necesita estrategias especiales.

💡

Guiar features

EDA visual sugiere transformaciones: log, polinomios, binning, interacciones.

🤝

Comunicar

Gráficos claros permiten validar suposiciones con stakeholders antes de modelar.

💡 Regla práctica: Antes de entrenar cualquier modelo, genera al menos: (1) distribución de cada variable, (2) heatmap de correlación, (3) conteo de missing values, (4) distribución del target.

🕳️ Valores Faltantes (Missing Values)

Un dataset real siempre tiene missing values. La estrategia correcta depende del mecanismo de missing: MCAR (aleatorio), MAR (relacionado con otros datos) o MNAR (relacionado con el valor mismo).

📐 Detección y Tratamiento de Outliers

Los outliers pueden ser errores de medición o señales valiosas. Antes de eliminarlos, entiende su causa. En ML supervisado, un outlier en el target puede sesgar completamente el modelo.

⚙️ Feature Engineering

Feature engineering es el arte de crear representaciones más informativas para el modelo. Un buen feature supera muchas veces a un modelo más complejo. 

import pandas as pd
import numpy as np

df = pd.read_csv('datos.csv', parse_dates=['fecha'])

# ── 1. Features temporales ─────────────────────────────
df['mes']         = df['fecha'].dt.month
df['dia_semana']  = df['fecha'].dt.dayofweek
df['es_finde']    = df['dia_semana'].isin([5, 6]).astype(int)
df['trimestre']   = df['fecha'].dt.quarter

# Encoding cíclico (evita salto 11→0 en meses)
df['mes_sin'] = np.sin(2 * np.pi * df['mes'] / 12)
df['mes_cos'] = np.cos(2 * np.pi * df['mes'] / 12)

# ── 2. Features de lag y rolling ──────────────────────
df = df.sort_values('fecha')
df['lag_7']        = df['ventas'].shift(7)
df['lag_30']       = df['ventas'].shift(30)
df['rolling_7']    = df['ventas'].rolling(7).mean()
df['rolling_30']   = df['ventas'].rolling(30).mean()

# ── 3. Transformaciones numéricas ─────────────────────
df['log_precio'] = np.log1p(df['precio'])   # log(1+x) para ceros
df['precio_bin'] = pd.cut(df['precio'], bins=5, labels=False)

# ── 4. Interacciones ──────────────────────────────────
df['ratio_precio_area'] = df['precio'] / (df['area'] + 1)

# ── 5. Encoding categórico ─────────────────────────────
df = pd.get_dummies(df, columns=['ciudad'], drop_first=True)  # OHE
df['target_enc'] = df.groupby('categoria')['target'].transform('mean')  # Target enc
💡 Regla de oro: Primero entiende el dominio — las mejores features vienen del negocio, no de combinaciones matemáticas aleatorias. Usa SelectKBest o feature_importances_ para validar su utilidad.

🤖 EDA Automatizado

Para exploración inicial rápida existen herramientas que generan un reporte completo en una sola línea. Son exploratorias — nunca sustituyen el EDA manual para datos de producción. 

# ── Opción 1: ydata-profiling (antes pandas-profiling) ────────────
pip install ydata-profiling

from ydata_profiling import ProfileReport
import pandas as pd

df = pd.read_csv('dataset.csv')
report = ProfileReport(df, title='EDA Report', explorative=True)
report.to_file('eda_report.html')   # Abre en el navegador
# o en Jupyter:
report.to_notebook_iframe()

# ── Opción 2: sweetviz ─────────────────────────────────────────────
pip install sweetviz

import sweetviz as sv
reporte = sv.analyze(df, target_feat='precio')
reporte.show_html('sweetviz_report.html')

# ── Opción 3: dtale (interactivo) ──────────────────────────────────
pip install dtale

import dtale
d = dtale.show(df)
d.open_browser()   # UI interactiva con filtros, correlaciones, etc.

# ── EDA mínimo propio (sin dependencias) ───────────────────────────
def eda_rapido(df):
    print(f"Shape: {df.shape}")
    print(f"\nDtypes:\n{df.dtypes}")
    print(f"\nMissing (%):\n{df.isna().mean().mul(100).round(1)}")
    print(f"\nDescribe:\n{df.describe().T}")
    print(f"\nDuplicados: {df.duplicated().sum()}")

eda_rapido(df)
⚠️ En producción estos reportes pueden tardar minutos en datasets grandes. Úsalos en la fase inicial de exploración, luego escribe EDA específico para las preguntas de negocio.
