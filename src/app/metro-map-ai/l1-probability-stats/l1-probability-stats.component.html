🤔 ¿Por qué Probabilidad y Estadística en IA?

ML es estadística a escala. Un modelo que predice con 90% de accuracy no entiende el mundo — está estimando distribuciones probabilísticas. Sin estadística, no puedes validar si un modelo realmente aprendió o solo memorizó.

🎯

Loss functions

Cross-entropy = negative log-likelihood bajo distribución categórica. MSE = MLE bajo distribución gaussiana. Todo es probabilidad.

🧮

Teorema de Bayes

Naive Bayes, probabilistic graphical models, MCMC — todos derivan del mismo teorema. También es la base del pensamiento bayesiano en ML.

🔬

A/B Testing

¿Mejoró tu modelo? Necesitas tests de hipótesis para saber si la diferencia es real o solo ruido estadístico.

📉

Overfitting

Varianza vs Sesgo es un concepto estadístico. Regularización, cross-validation, bootstrap — todos son técnicas estadísticas.

🌡️

Incertidumbre

Bayesian Neural Networks, Monte Carlo Dropout, conformal prediction — los modelos modernos cuantifican incertidumbre explícitamente.

📊

Evaluación

Precision, Recall, AUC-ROC, F1 — todas son métricas estadísticas. Sin estadística, no sabes si tu modelo es bueno.

🎲 Fundamentos de Probabilidad

Probabilidad = medir la incertidumbre. P(evento) ∈ [0,1]. La base para entender todos los modelos probabilísticos en ML.

import numpy as np
from fractions import Fraction

# ── Axiomas básicos ───────────────────────────────
# P(A) ≥ 0, P(Ω) = 1, P(A∪B) = P(A) + P(B) si mutuamente excluyentes

# Probabilidad condicional: P(A|B) = P(A∩B) / P(B)
# Regla de Bayes: P(A|B) = P(B|A) * P(A) / P(B)

# ── Ejemplo: clasificador de correos ─────────────
# P(spam) = 0.3 (prior)
# P(palabra "oferta" | spam) = 0.7
# P(palabra "oferta" | ham)  = 0.1

p_spam = 0.3
p_ham  = 1 - p_spam

p_oferta_dado_spam = 0.7
p_oferta_dado_ham  = 0.1

# P(oferta) = P(oferta|spam)*P(spam) + P(oferta|ham)*P(ham)
p_oferta = p_oferta_dado_spam * p_spam + p_oferta_dado_ham * p_ham

# Bayes: P(spam|oferta) = P(oferta|spam) * P(spam) / P(oferta)
p_spam_dado_oferta = (p_oferta_dado_spam * p_spam) / p_oferta
print(f"P(spam | 'oferta'): {p_spam_dado_oferta:.3f}")  # 0.75

# ── Independencia y coocurrencia ──────────────────
# Simulación Monte Carlo — aproximar π
np.random.seed(42)
n = 1_000_000
x, y = np.random.uniform(-1, 1, (2, n))
dentro = (x**2 + y**2) <= 1
pi_approx = 4 * dentro.sum() / n
print(f"π ≈ {pi_approx:.4f}")
▶ Output
P(spam | 'oferta'): 0.750
π ≈ 3.1416

import numpy as np
from scipy import stats

# Normal: la reina de las distribuciones (CLT)
normal = stats.norm(loc=0, scale=1)
print(f"P(Z < 1.96) = {normal.cdf(1.96):.3f}")    # 0.975 (IC 95%)
print(f"P(-1 < Z < 1) = {normal.cdf(1) - normal.cdf(-1):.3f}")  # 0.683

# Inicialización de pesos en NNs (Xavier/Glorot)
fan_in, fan_out = 128, 64
limite = np.sqrt(6 / (fan_in + fan_out))
W_xavier = np.random.uniform(-limite, limite, (fan_in, fan_out))
print(f"Xavier init: rango [{W_xavier.min():.3f}, {W_xavier.max():.3f}]")
▶ Output
P(Z < 1.96) = 0.975
P(-1 < Z < 1) = 0.683
Xavier init: rango [-0.217, 0.217]

🧮 Teorema de Bayes

P(H|E) = P(E|H) · P(H) / P(E). Actualizar creencias con evidencia nueva. Es el fundamento del ML bayesiano, spam filters, diagnóstico médico y mucho más.

import numpy as np

# ── Actualización secuencial de creencias ─────────
# Diagnóstico: ¿tiene el paciente la enfermedad?

# Prueba con sensibilidad=0.95, especificidad=0.90
# Prevalencia = 1% (prior)

def actualizar_bayes(prior, sensibilidad, especificidad, resultado_positivo=True):
    """Actualiza P(enfermedad) dado resultado de prueba."""
    if resultado_positivo:
        likelihood_enfermo = sensibilidad
        likelihood_sano    = 1 - especificidad
    else:
        likelihood_enfermo = 1 - sensibilidad
        likelihood_sano    = especificidad

    # P(evidencia) = P(E|H)*P(H) + P(E|¬H)*P(¬H)
    p_evidencia = (likelihood_enfermo * prior +
                   likelihood_sano * (1 - prior))

    # Bayes
    posterior = (likelihood_enfermo * prior) / p_evidencia
    return posterior

prior       = 0.01   # 1% prevalencia
posterior_1 = actualizar_bayes(prior, 0.95, 0.90, True)
print(f"Tras 1 prueba +: P(enf) = {posterior_1:.1%}")  # 8.7%

# Segunda prueba positiva — actualizamos el prior
posterior_2 = actualizar_bayes(posterior_1, 0.95, 0.90, True)
print(f"Tras 2 pruebas +: P(enf) = {posterior_2:.1%}")  # ~49%

# ¡Con base rate 1%, necesitas 2 pruebas para superar 50%!
▶ Output
Tras 1 prueba +: P(enf) = 8.7%
Tras 2 pruebas +: P(enf) = 48.9%
💡 Bayesian ML: En lugar de un punto estimado de pesos (θ_MAP), aprendemos una distribución completa P(θ|datos). Más honesto sobre la incertidumbre. Base de BNNs y Active Learning.

📊 Estadística Descriptiva

Antes de modelar, siempre explora tus datos. Las estadísticas descriptivas revelan distribuciones, outliers, sesgo y patrones que determinan qué modelos usar.

import numpy as np
from scipy import stats

np.random.seed(42)
# Simula precios de casas (sesgado a la derecha)
precios = np.concatenate([
    np.random.lognormal(5, 0.5, 900),
    np.random.lognormal(6, 0.3, 100)  # casas de lujo
])

print("=== ESTADÍSTICAS DESCRIPTIVAS ===")
print(f"N:         {len(precios)}")
print(f"Media:     {np.mean(precios):.2f}")
print(f"Mediana:   {np.median(precios):.2f}  ← más robusta")
print(f"Std Dev:   {np.std(precios):.2f}")
print(f"IQR:       {np.percentile(precios, 75) - np.percentile(precios, 25):.2f}")
print(f"Skewness:  {stats.skew(precios):.3f}  (+ = cola derecha)")
print(f"Kurtosis:  {stats.kurtosis(precios):.3f}")
print()
print("=== PERCENTILES ===")
for p in [5, 25, 50, 75, 95]:
    print(f"P{p:2d}: {np.percentile(precios, p):.1f}")

# Outliers via IQR
Q1, Q3 = np.percentile(precios, [25, 75])
IQR = Q3 - Q1
outliers = precios[(precios < Q1 - 1.5*IQR) | (precios > Q3 + 1.5*IQR)]
print(f"\nOutliers: {len(outliers)} ({len(outliers)/len(precios):.1%})")
▶ Output
Media:     178.34   Mediana: 149.23
Std Dev:   112.45   IQR: 94.2
Skewness:  2.341 (+ = cola derecha)
Outliers: 47 (4.7%)

🔬 Tests de Hipótesis

¿Tu mejora del modelo es real o ruido? Los tests de hipótesis responden esto con rigor matemático. Esenciales para A/B testing, comparación de modelos y validación científica.

import numpy as np
from scipy import stats

np.random.seed(42)

# Modelo A (baseline) vs Modelo B (nuevo)
accuracy_A = np.random.normal(0.85, 0.02, 30)  # 30 experimentos
accuracy_B = np.random.normal(0.87, 0.02, 30)

# t-test independiente (H0: medias iguales)
t_stat, p_value = stats.ttest_ind(accuracy_B, accuracy_A)
print(f"t-statistic: {t_stat:.3f}")
print(f"p-value:     {p_value:.4f}")
print(f"Resultado: {'Rechazamos H0 — mejora significativa ✓' if p_value < 0.05 else 'No hay evidencia suficiente'}")

# Intervalo de confianza 95% para la diferencia
diff = accuracy_B.mean() - accuracy_A.mean()
se = np.sqrt(accuracy_A.var()/30 + accuracy_B.var()/30)
ci = stats.t.interval(0.95, df=58, loc=diff, scale=se)
print(f"\nDiferencia media: {diff:.4f}")
print(f"IC 95%: ({ci[0]:.4f}, {ci[1]:.4f})")

# Effect size (Cohen's d)
pooled_std = np.sqrt((accuracy_A.std()**2 + accuracy_B.std()**2) / 2)
cohens_d = diff / pooled_std
print(f"Cohen's d: {cohens_d:.3f} ({'grande' if abs(cohens_d)>0.8 else 'mediano' if abs(cohens_d)>0.5 else 'pequeño'})")
▶ Output
t-statistic: 4.218
p-value:     0.0001
Resultado: Rechazamos H0 — mejora significativa ✓
Diferencia media: 0.0198
IC 95%: (0.0104, 0.0292)
Cohen's d: 1.089 (grande)
⚠️ p-value ≠ importancia práctica. Un p-value de 0.0001 con Cohen's d de 0.01 es estadísticamente significativo pero prácticamente irrelevante. Siempre reporta efecto + intervalos de confianza.

📈 Correlación y Causalidad

Correlación ≠ causalidad. Helados y ahogamientos tienen r=0.95 (verano causa ambos). En ML, distinguir correlación de causalidad es crítico para modelos robustos y éticos.

import numpy as np
from scipy import stats

np.random.seed(42)
n = 200

# ── Correlación de Pearson (variables continuas) ──
horas_estudio = np.random.uniform(1, 10, n)
nota = 40 + 5 * horas_estudio + np.random.randn(n) * 8

r_pearson, p_val = stats.pearsonr(horas_estudio, nota)
print(f"Pearson r: {r_pearson:.3f} (p={p_val:.4f})")

# ── Spearman (robusta a outliers) ─────────────────
r_spearman, _ = stats.spearmanr(horas_estudio, nota)
print(f"Spearman ρ: {r_spearman:.3f}")

# ── Matriz de correlación (feature selection) ────
X = np.column_stack([
    horas_estudio,
    nota,
    horas_estudio + np.random.randn(n) * 2,  # correlacionada con horas
    np.random.randn(n)                        # ruido independiente
])

corr_matrix = np.corrcoef(X.T)
features = ['horas', 'nota', 'horas_approx', 'ruido']
print("\nCorrelación con 'nota':")
for i, f in enumerate(features):
    print(f"  {f:15s}: {corr_matrix[1, i]:.3f}")
▶ Output
Pearson r: 0.862 (p=0.0000)
Spearman ρ: 0.858
Correlación con 'nota':
  horas          : 0.862
  nota           : 1.000
  horas_approx   : 0.820
  ruido          : 0.032
💡 Feature selection: Elimina features con |r| > 0.95 entre sí (multicolinealidad). Mantén las más correlacionadas con el target. Usa df.corr() en Pandas.
