⚠️ IMPORTANTE: Prompt Engineering para Developers

El Mito del "ChatGPT hace todo el código"

❌ Developer Casual

Prompt genérico:
"Hazme un microservicio en Java"

• Acepta código sin revisar

• No considera contexto del proyecto

• Copia/pega sin entender

✅ Prompt Engineer Profesional

Prompt estructurado:
"Actúa como arquitecto Java. Spring Boot 3.2, Java 17. Microservicio REST de Gestión de Préstamos para banca..."

• Valida arquitectura, patrones, seguridad

• Especifica versiones, dependencias

• Analiza, adapta y mejora el código

⚡ CLAVE: La IA multiplica tu productividad cuando le das contexto preciso del stack, arquitectura y restricciones del proyecto.

🔥 Módulo 2: Backend Development con IA (4 sesiones)

Clase 2: Generación de Microservicio Spring Boot

60 minutos

Reto: Crear microservicio de Gestión de Clientes desde cero

📦 Stack:

Java 17, Spring Boot 3.2, Spring Data JPA, Lombok, MapStruct

✨ Entregable:

Microservicio funcional con Swagger, listo para deploy

🎯 Lo que aprenderás:

  • Arquitectura hexagonal completa
  • DTOs con validaciones Bean Validation
  • Repository con consultas personalizadas
  • Service con lógica de negocio
  • Controller REST con OpenAPI/Swagger
  • Tests unitarios (JUnit 5 + Mockito)

Clase 3: Migración Legacy VB6 a Spring Boot

60 minutos

Reto: Analizar módulo VB6 existente y migrar a Spring Boot moderno

🔄 Casos de Migración:

  • Consultas SQL nativas → JPA Criteria/JPQL
  • Validaciones en formulario → Bean Validation
  • Lógica en UI → Service layer
  • Conexiones DB directas → Spring Data Repository

✨ Entregable:

Módulo migrado + documento de equivalencias funcionales

Clase 4: Integración con APIs Externas

60 minutos

Reto: Integrar microservicio con API externa (Bureau de Crédito)

📦 Stack:

Spring Boot, WebClient, Resilience4j, Redis/Caffeine Cache

🎯 Lo que aprenderás:

  • Cliente REST con WebClient
  • Circuit breaker con Resilience4j
  • Manejo de timeouts y retry policies
  • Caché de respuestas con Spring Cache
  • Tests con WireMock

Clase 5: Testing Avanzado con IA

60 minutos

Reto: Suite completa de tests para microservicio existente

📦 Stack:

JUnit 5, Mockito, Testcontainers, Spring Cloud Contract, JaCoCo

✨ Entregable:

Suite completa de tests + reporte de cobertura >80%

🚀 Mejores Prácticas para Developers

✅ DO's (Hacer)

Especificar versiones exactas
✅ "Spring Boot 3.2.1, Java 17"
Incluir contexto de arquitectura
✅ "Microservicio con arquitectura hexagonal"
Pedir tests junto con código
✅ "Genera código + tests unitarios con cobertura >80%"
Validar seguridad
✅ Revisar SQL injection, XSS, secretos hardcoded

❌ DON'Ts (Evitar)

Prompts demasiado amplios
❌ "Hazme un sistema bancario completo"
Copiar/pegar sin revisar
❌ Usar código generado sin análisis
Ignorar el contexto del proyecto
❌ Generar código incompatible con el stack actual
Olvidar casos edge
❌ Solo implementar path feliz
