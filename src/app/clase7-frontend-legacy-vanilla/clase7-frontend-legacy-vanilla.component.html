📝 Template de Prompt para Frontend Legacy

Genera una aplicación web CRUD de [ENTIDAD] en Vanilla JavaScript puro que consuma la siguiente API REST:

**Contexto:**
- Backend: [TECNOLOGÍA] corriendo en [URL]
- Endpoints disponibles:
  * GET /api/[entidad] (listar todos)
  * POST /api/[entidad] (crear, body JSON: {{ '{' }}campo1, campo2, campo3{{ '}' }})
  * PUT /api/[entidad]/{{ '{' }}id{{ '}' }} (actualizar)
  * DELETE /api/[entidad]/{{ '{' }}id{{ '}' }} (eliminar)
- Modelo: {{ '{' }}id, campo1, campo2, campo3{{ '}' }}

**Requerimientos técnicos:**
- HTML en un solo archivo index.html
- CSS inline o en {{ '<' }}style{{ '>' }} tag
- JavaScript puro en {{ '<' }}script{{ '>' }} tag (sin módulos ES6)
- fetch() para llamadas HTTP (incluir headers JSON)
- DOM manipulation con document.getElementById/querySelector
- Event listeners inline (onclick) o .addEventListener
- Tabla HTML para mostrar [entidad] (con botones Editar/Eliminar)
- Formulario para Crear/Actualizar (reusar mismo form)
- Variables globales para estado ([entidad]Editando, etc)
- Manejo básico de errores (alert/console.log)

**Características legacy intencionales:**
- Código en un solo archivo
- innerHTML para actualizar tabla completa
- Sin validaciones cliente complejas
- Lógica mezclada con presentación
- Variables globales para estado
- Callbacks anidados

**Entregable:**
Archivo index.html completo con HTML + CSS + JS funcional.

🎯 Variables a personalizar:

  • [ENTIDAD]: clientes, productos, usuarios, pedidos, etc.
  • [TECNOLOGÍA]: Spring Boot, Node.js Express, Django, etc.
  • [URL]: http://localhost:8080, https://api.miapp.com, etc.
  • {{ '{' }}campo1, campo2, campo3{{ '}' }}: atributos del modelo (nombre, email, etc.)
