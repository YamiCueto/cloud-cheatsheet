## 📝 Post 2: Dev.to / Medium Article

### Título
Cómo construí un dashboard interactivo para aprender AWS (y por qué deberías usarlo)

### Introducción

Después de 6 meses preparándome para certificaciones AWS, me di cuenta de algo:

**La documentación oficial de AWS es increíble... pero abrumadora.**

Necesitas abrir 20 pestañas para entender un solo servicio. Los cheatsheets PDF ayudan, pero son estáticos. Y los cursos en video son lentos cuando solo necesitas refrescar un concepto.

Así que construí **Cloud Cheatsheet** - un dashboard interactivo que es tu compañero visual para dominar AWS.

### El Problema que Resuelve

Como desarrollador hispano, enfrenté estos desafíos:

1. **Sobrecarga de información**: AWS tiene 200+ servicios
2. **Documentación fragmentada**: Cada servicio en su propia página
3. **Falta de contexto práctico**: ¿Cuándo usar S3 vs EBS vs EFS?
4. **Preparación para certificaciones**: ¿Por dónde empezar?

### La Solución

Un dashboard de Angular con:

#### 🔍 Búsqueda Inteligente
Escribe "storage" y ve instantáneamente S3, EBS, EFS, Glacier...

#### 📊 Organización Visual
60+ servicios organizados en categorías:
- ☁️ Compute (EC2, Lambda, ECS...)
- 💾 Storage (S3, EBS, EFS...)
- 🗄️ Database (RDS, DynamoDB, Aurora...)
- 🔒 Security (IAM, KMS, Cognito...)

#### 💻 Ejemplos Multi-lenguaje
Para cada servicio, código listo para copiar en:
- AWS CLI
- Node.js (SDK v3)
- Python (Boto3)
- Java

#### 🗺️ Roadmaps de Certificación

Lo más valioso: planes estructurados para 4 certificaciones AWS:

**Cloud Practitioner (CLF-C02)** - 8 semanas
- Semana 1-2: Fundamentos
- Semana 3-4: Compute & Storage
- Semana 5-6: Security & Billing
- Semana 7-8: Práctica intensiva

**Solutions Architect (SAA-C03)** - 12 semanas
- Arquitectura Well-Architected
- IAM y seguridad avanzada
- Networking (VPC, subnetting)
- Alta disponibilidad y DR

**Developer (DVA-C02)** - 10 semanas
- Lambda y serverless
- DynamoDB para developers
- CI/CD (CodePipeline, CodeBuild)
- Debugging con X-Ray

**SysOps (SOA-C02)** - 10 semanas
- Monitoring con CloudWatch
- Systems Manager
- Deployment automation
- Cost optimization

Cada roadmap incluye:
✅ Progreso persistente (localStorage)
✅ Recursos gratuitos y pagos
✅ Info detallada del examen
